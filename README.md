# 鼎山打字通

一款 Windows 打字练习工具，包含中英文短文、代码录入、四六级词汇贪吃蛇和最多四人的局域网联机。

## 开始使用

从 [Releases](../../releases/latest) 下载 EXE，双击运行。单人练习可离线使用。

首次启动时注册本地昵称，之后点击「登录」即可进入。昵称保存在本机，局域网建房和加入时会自动填入；也可以在联机面板修改。八套主题都有自己的开场动效和音效，开场可跳过，并遵循 Windows 的动画设置。

- **外观设置**从练习页右上角进入，可选现代、极简、赛博朋克、蒸汽朋克、蒸汽波、构成主义、P5 风格和国风。点击「保存并重启」后，整个应用会使用选中的风格。
- **短文练习**包含 50 篇原创四级英语短文和约 200 字的现代中文短文。英文统计 WPM，中文可用系统输入法并统计每分钟正确汉字数。支持换文、重练、标点设置和打击感。
- **代码练习**包含 C、C++、Python 各 50 份示例。按原样输入大小写、符号和换行，Tab 插入 4 个空格。开启「打击感」后，输入代码有按键声，完整打对代码词会触发文字残影和轻震。
- **练习字体**可在打字页切换，原文和输入框一起更新，下次启动保留选择。EXE 内置四款 SIL OFL 1.1 字体，汉字继续使用系统中文字体。字体许可证位于 `fonts/`。[JetBrains Mono](https://github.com/JetBrains/JetBrainsMono/tree/v2.304) · [IBM Plex Mono](https://github.com/IBM/plex/tree/master/packages/plex-mono) · [Source Code Pro](https://github.com/adobe-fonts/source-code-pro/tree/release) · [Atkinson Hyperlegible](https://github.com/googlefonts/atkinson-hyperlegible)
- **打击感**在手动练习和 AutoPlay 中都按当前主题播放。按键、词语完成和整轮完成有不同的声音与动效，例如蒸汽朋克的棘轮声、齿轮和喷汽，以及国风的拨弦、墨韵和朱印。
- **AutoPlay**按 100 WPM 演示当前练习，可随时停止。演示不计分。
- **本地排行榜**为四级英语、现代中文、各语言及题型的代码练习、各词库的词汇复习分别保存成绩。可查看速度、准确率和综合分前三名。综合分为速度 × 准确率²，首次完成或刷新本类型的综合纪录时显示祝贺弹窗。成绩保存在 `%LOCALAPPDATA%\EnglishTypingPractice\settings.json`，在同一 Windows 用户下更换 EXE 会继续读取。完成一轮后按空格即可换下一篇、下一题或下一个复习词。
- **练习复盘**显示速度、正确率、常错字符和最耗时的词。重练本篇可以比较两轮成绩。代码可以选择括号、引号、缩进或完整程序，并单独统计符号和缩进错误。中文按输入法确认上屏的文字计时和统计。
- **贪吃蛇词汇复习**从本机保存能识别的错词和主动清除的词，可按四级或六级筛选。打对后才显示中文释义。
- **背景音乐**可读取本地音乐文件夹及其子文件夹，支持手动播放、暂停和拖动进度，也支持练习时自动播放、选歌、调音量、顺序循环、随机播放和单曲循环。
- **贪吃蛇**用英文词转向。方向词按上、下、左、右排在十字形面板里，每个词附中文释义。输入 `start` 开局。指令框只接收英文字母，大写自动转为小写。空格清空当前输入框，有技能的职业用 `Tab` 切换输入框，技能短语连写。
- **玩法规则**可从贪吃蛇页打开，包含快速开局、八种模式和各职业说明。单人和联机对局的蛇头气泡会显示玩家当前输入的字母，并标记技能输入。打完有效方向词或技能词后，棋盘上方会短暂显示单词与中文释义。
- **互动引导**从玩法规则进入，选择职业后按步骤练习打词转向、锁定视角、暂看周围、清空输入和职业能力。
- **经典模式**单人开局前可将地图边长设为 32–128 格，默认 32 格。每分钟将可活动区域的边长缩小 5 格，最小为 7 × 7。圈外视为撞墙。
- **棋盘视野**以 32 × 32 格显示，按 `Alt` 切换。自由视角在蛇接近视野边缘时平移。锁定视角保持蛇头居中，按住方向键可暂时查看周围，松开即归位。锁定视角和较大的地图会显示小地图，标出视野覆盖的地图范围及玩家位置。
- **对局反馈**转向时会轻微震动并显示彩色叠影。狩猎者子弹有拖尾，狩猎者与吟唱者都有技能特效。大果生成时，棋盘上的橙色箭头会指向它。可勾选「英文女声」朗读完成的词，使用 Windows 已安装的英文女声。
- **棋盘可读性**远处对手只显示昵称，大果在视野外时用边缘箭头指路。勾选「低特效」可减弱震动和动画，保留子弹和技能判定提示。
- **本局复盘**在经典和障碍赛查看存活时长、死因和转向次数。圈地战显示占地得失，团战显示交付和复活次数。各赛制均记录技能命中。
- **障碍赛**开局随机放置四格方块障碍，出生区保留无障碍的起步空间。撞上障碍会按碰撞处理，果子不会生成在障碍上。
- **带障碍的赛道**也会保护开局和复活位置，给蛇头留出至少六格无障碍直行空间和起步转向空间。
- **迎头相撞**在对战中会让双方同时出局，包括同时进入同一格、相邻两格对穿，以及撞上尚未移动的蛇头。可以复活的赛制沿用各自的复活规则。
- **圈地战**为每名玩家分配颜色，走回自己的轨迹时会占领闭环及其内部的格子，可以夺取其他玩家的地盘。蛇头被对手圈住或撞墙会回到起点。每分钟基础移速乘以 1.2，五分钟后按占地格数排名，同分并列。
- **时空者**使用 6、8、10 字母的方向词。经典和障碍赛分别额外前进 0、1、2 格，转向固定加 6 分，最长词可用于直行加速，直行不计分。圈地战和团战分别额外前进 0、2、4 格。
- **胆怯者**以平凡者移速的 85% 移动，使用 5–6 字母的词转向，在经典和障碍赛中有一条命。
- **无畏者**在圈地战使用 100% 基础移速，其余模式为 120%。输入技能词可冲锋 1 秒，使穿过的对手僵直 3 秒。
- **团战**支持单人添加人机及局域网。房主选择 2–4 队，玩家随机均分。60×60 的棋盘平分给各队，每队开局有 5 颗球。己方球可以穿过，碰到敌方球会自动捡起。回到己方区域后按 `Shift` 每次放下一颗，球会变为己方颜色。每球扣 10% 移速，最低为原移速的 10%。空手按住 `Shift` 提速 25%，松开恢复。死亡时携带的球回原队，15 秒后在己方区域复活。8 分钟后，按已经落地归属各队的球数决定胜负。
- **镜像竞速**支持单人计时和 2–4 人局域网。每位选手独立跑同一张 48×48 地图，依次经过 6 个 3×3 检查点。只标出下一站，联机小地图旁显示选手进度。撞车回上一个检查点并罚时 5 秒。限时 3 分钟，完赛按含罚时的成绩排名，未完赛按通过检查点数和最后一站用时排名。单人固定地图按职业保存最佳成绩，房主可勾选统一使用房主职业。
- **四区供电**是 2–4 人合作，支持人机队友。蛇头在启用中的 5×5 供电区内完成一次有效转向，可贡献 1 格电。2／3／4 人时每站需 4／5／6 格。每 45 秒一座站停用 10 秒，小地图提前 5 秒预告。可穿过队友，撞车 5 秒后复活。5 分钟内充满四站即可通关，结算显示个人贡献。镜像竞速与四区供电关闭狩猎者和吟唱者的攻击技能。
- **热点争夺**是 2–4 人混战。独占 7×7 热点时每秒得 1 分，多人进入时暂停计分。热点每 30 秒换位，小地图提前 5 秒标出下一处。出局后等 5 秒复活，4 分钟后按热点积分排名。
- **词牌接力**四人随机分成两队，各队在独立的同一条赛道轮流跑四棒。抵达交接区后，下一棒打完 6–7 字母接力词才出发。撞车等 5 秒回本棒起点，这段时间计入成绩。先跑完四棒获胜；4 分钟内均未完赛时，先比完成棒数，再比到达最近交接区的时间。关闭攻击技能。
- **人机玩家**开局前可选 0–3 个，难度分为简单、普通、困难和地狱。单人可和人机对抗或合作；局域网由房主配置，真人和人机合计最多四席。地狱人机打字更快，也会预判转向后的退路和对手可能经过的位置。
- **狩猎者**输入 15–20 字母后，朝前发射速度为自身 3 倍的子弹，击中对手蛇身即判定死亡。**吟唱者**输入同长度的技能词后，对以蛇头为中心的 5 × 5 格瞬间判定，命中范围内的对手蛇头。圈地战中被技能击中的玩家回到起点。
- **领航者**每完成三个常规方向词，下个方向词缩短。通常使用 7–8 字母常规词、4 字母短词，圈地战分别为 6–7 和 5 字母。经典和障碍赛转向固定加 6 分。
- **采集者**在经典和障碍赛转向加 5 分，小果加 14 分，大果加 38 分。团战每带一颗球扣 8% 移速。
- **稳行者**按 `Tab` 输入 9–11 字母的技能词，可在保持转向的同时用 70% 移速前进 2.5 秒。经典施放加 5 分，障碍赛加 8 分。圈地战的效果为 85% 移速、1.5 秒，并有从发动时计起的 40 秒冷却。
- **局域网联机**由房主建房，同一网络的玩家扫描后加入。扫描不到时，可输入房主的 IPv4 地址。所有人使用同一版本，房主输入 `start` 开局。大果优先生成在离各玩家蛇头距离相近的位置。
- **房间续局**扫描结果显示赛制、人数、版本和开局状态。房主可从结算返回准备，成员准备后继续，团战重新随机分队。成员短暂掉线时有 20 秒回到原席位，对局继续计时。
- **房间昵称**会显示在名单、蛇头气泡和排行榜中。同房昵称完全相同时，按席位顺序添加 `#1`、`#2` 等编号。本地保存的昵称保持原样，断线重连回原席位。
- **房间音乐**由房主读取本机 `E:\dingshan` 并在对局中播放，成员在同一局域网内接收，无需准备同一份音乐。房主可设全房音乐音量，每人可分别调整自己听到的音乐和游戏音效。

## 从源码构建

在安装了 .NET Framework 4.8 或更新版本的 64 位 Windows 上，于源码目录运行 PowerShell：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Build.ps1
```

构建后，`DingshanTyping.exe` 位于源码目录。程序、图标和词库一起打包进这个文件。
